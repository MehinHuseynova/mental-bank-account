# Design reference

Measured from the onboarding PNGs in `Onboarding/`. Images are 2x exports of a 390 × 844 pt screen, so divide pixels by 2. Sizes are approximate; check on the phone.

**Colors**
| Token | Hex | Used for |
|---|---|---|
| `background` | `#F3F5F1` | screen background, info box inside cards |
| `surface` | `#FFFFFF` | cards, time picker |
| `border` | `#E1E6E1` | card borders |
| `primary` | `#2E6B5E` | buttons, active dot, eyebrow, icons, "done" days |
| `onPrimary` | `#FFFFFF` | button text |
| `textPrimary` | `#1E2B2A` | titles, big time digits |
| `textSecondary` | `#44524F` | body paragraphs |
| `textMuted` | `#5B6B68` | Skip, Not now, card descriptions |
| `dotInactive` | `#C5D0CB` | inactive pager dots |
| `illustrationBg` | `#E8EEE9` | circle behind the illustration |
| `dayEmpty` | `#E9EDEA` | future days in the week strip |
| `dayMissed` | `#A9B6B1` | dashed outline of a missed day |
| `gold` | `#E0A630` | coins in the illustration |
| `effort` | bg `#E2EFEA` · fg `#2E6B5E` | E tile |
| `success` | bg `#F6EDD8` · fg `#8A5A00` | S tile |
| `progress` | bg `#E3ECF5` · fg `#2F5F8A` | P tile, moon tile |

**Typography: Nunito.** Title ~34 pt ExtraBold · body ~17 pt Regular · eyebrow ~14 pt Bold uppercase, letter spacing ~2 · card title ~18 pt Bold · card text ~15 pt · button ~17 pt Bold · time digits ~40 pt ExtraBold.

**Sizes (pt).** Side padding 28 · button height 56, radius ~16 · card radius ~20 with 1 pt border · letter/icon tiles 48 × 48, radius ~12 · pager dots 8 × 8, active 24 × 8.
